# Arbora | Where People Find Their People

Arbora is a lifestyle & community brand built around people, music, nature, and experiences.

## Repository Overview
This repository contains the standalone, production-ready codebase for **Arbora Retreats & Experiences**.

### Key Pages & Features
- **Main Landing Page (`/`)**: Community-first hero ("Where People Find Their People"), clean manifesto ("Intentional Spaces • Familiar Faces"), Community Matcher quiz, property setting framing (Sura Stays, Mudigere), The Arbora Way (7 beliefs), Meet the Arborans, inclusions, community formats, and merged full Team, Founder & Investor (Chukki Talkies) section.
- **30-Experience Directory (`/cohorts`)**: Filterable master directory across Milestones, Identity, and Wellness & Adventure categories.
- **Why We Exist (`/team`)**: Dedicated team, founder vision, platform leads (Harsha Janardhana Giri, Kavya M), and Chukki Talkies strategic partnership.

## Deployment on Vercel
1. Import this repository (`https://github.com/arboraretreats-create/Arbora_Retreats.git`) in your [Vercel Dashboard](https://vercel.com/new).
2. Framework Preset: **Next.js** (automatically detected).
3. Click **Deploy**.
